## Proposed bounded project

**Control Where It Counts: Testing Human Oversight in Agent Workflows** is a proposed 12-week, $35,000 open-source research pilot under focus area **3. Human Empowerment**. It would compare no approval, nominal approval, and a meaningful veto across matched synthetic agent-action scenarios. Proposed outputs: a reproducible evaluation harness, preregistered error metrics, and an evidence-based decision guide for where human review adds value. No empirical result, funded team, or real-world intervention is claimed.

The project reuses existing [Human Kind agent-authority boundaries](https://github.com/Svyable/human-kind/blob/main/docs/agent-protocol.md) and [ScrolIQ provenance practices](https://github.com/Svyable/scrollq). It is distinct from Svyable's TAIF *Control Evidence* proposal: this project tests **control allocation and causal intervention value**; TAIF tests **post-hoc claim/trace reconciliation**. No double billing.
