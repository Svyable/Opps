## Proposed application answers (draft; NOT assertions of proven performance)
### What are you working on?
Svyable is building tools that make consequential claims auditable rather than merely persuasive. Existing Control Evidence experiments show a precise failure mode: matching file bytes alone do not establish that an authorized agent performed an action. Our negative controls label such evidence OBSERVED_ONLY, and we are developing falsifiable evaluation gates that compare false-support rates against a baseline. This project will extend those techniques to public-facing provenance and decision evidence: attach inspectable source trails, classify claims as observed versus independently verified, and quantify how often the interface leads reviewers to falsely accept unsupported claims. The goal is improved epistemic calibration, not centralized truth arbitration.

### What would you do with funding?
Proposed 12-week pilot, conditional on verified ownership, staffing and budget:
1. Publish a small open evaluation dataset of source/claim/action evidence cases with explicit provenance and permission checks.
2. Build a reusable claim-evidence schema and scorer, using existing Svyable Control Evidence code and the Svenn Diagram decision-comparison concept where rights permit.
3. Run blinded baseline-versus-evidence-assisted review experiments with preregistered sample sizes, confidence intervals, failure thresholds and reproducible scripts.
4. Release a technical report, limitations, demo, and funder update. No claim of independently authenticated action unless recorder custody and identity are actually validated.
