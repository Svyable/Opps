Agent contract

Canonical structured state: /Opps/registry.json. Read that before scraping this page. Preserve the controlled vocabulary OPEN / PURSUE / WATCH / REJECT / WON / LOST. Never silently convert estimates into payer-stated values. Never make binding submissions, spend money, or assert eligibility evidence that has not been verified. A useful agent run should change the state of one highest-EV opportunity by producing evidence, a submission artifact, a measured experiment, a compliance check, or a justified status transition.
